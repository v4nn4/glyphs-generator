v4nn4.github.io/glyphs-generator

Draw a glyph by dragging lines between the anchor points. All glyphs that can be generated from your strokes will appear on the right.

Strokes on a 3×3 grid allow for 236 ≈ 69 billion possible glyphs. Using symmetry and connectivity rules, we bring this down to a small set of distinct, usable symbols (see companion blog post).
